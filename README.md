# KI-Content Business

## Projektbeschreibung
Dieses Projekt ermöglicht die **automatisierte Erstellung von KI-gestützten Content-Produkten** wie Videos, Landingpages und Marketing-Materialien für Unternehmen. Ziel ist es, hochwertige Inhalte schnell und skalierbar zu generieren.

## Technologien
- **Frontend:** Vanilla HTML5, Tailwind CSS (CDN), Vanilla JavaScript
- **Tools:** Git, Node.js, HyperFrames für Video-Produktion
- **Datenbank:** JSON-basierte Videodatenbank

## Installation
1. Klone das Repository:
   ```bash
   git clone <repository-url>
   cd KI_Content_Business
   ```

2. Installiere die Abhängigkeiten:
   ```bash
   npm install
   ```

3. Starte den lokalen Server:
   ```bash
   npm start
   ```

## Projektstruktur
- `/video01` - Hauptvideoprojekte
- `/assets` - Medienressourcen
- `/components` - Wiederverwendbare UI-Komponenten
- `/docs` - Dokumentation und Blogbeiträge

## Nutzung
1. Erstelle neue Videos über die HyperFrames-Schnittstelle
2. Nutze die Landingpage-Templates für Marketingzwecke
3. Optimieren Sie Assets für maximale Performance
